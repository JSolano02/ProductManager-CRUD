# ProductManager-CRUD

Proyecto académico de Programación III (ITLA). Sistema de gestión de productos con HTML, CSS y JavaScript, sin dependencias externas.

## Ejecución local

Abrir `index.html` en un navegador. Se recomienda usar un servidor local (por ejemplo, Live Server en VS Code) y mantener la misma dirección durante las pruebas, para conservar los datos de LocalStorage.

## Funcionalidades previstas

- Registro de productos.
- Consulta de catálogo y resumen del inventario.
- Edición de productos.
- Eliminación de productos.
- Búsqueda y validación de datos.

## Flujo de trabajo

La práctica utiliza `main`, `dev`, `qa` y cinco ramas `feature/`. Cada funcionalidad se integra mediante Pull Requests hacia las tres ramas de destino, según las indicaciones de la asignación.
